# Security policy

## Reporting a vulnerability

Send suspected security issues privately to [support@kaldenframelabs.com](mailto:support@kaldenframelabs.com) with `Security` in the subject line.

Please include the affected repository and version, the observed behavior, the smallest safe reproduction you can provide, and any relevant file hashes. Do not include credentials, private customer data, proprietary datasets, or sensitive production logs. Do not open a public issue containing exploit details or other sensitive material.

Current public releases and their documented boundaries are listed at [kaldenframelabs.com/releases](https://kaldenframelabs.com/releases/). A hash match identifies the exact published bytes; it is not a signature, vulnerability assessment, or guarantee of safety.

This repository does not operate a bug bounty or promise a specific response or remediation timeline.
